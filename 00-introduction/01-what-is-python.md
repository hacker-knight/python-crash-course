# Features of Python

## High-Level Language

Python hides low-level system details from developers.

This allows programmers to focus on solving problems instead of memory management.

---

## Interpreted Language

Python code is executed line by line using an interpreter.

Benefits:
- Easier debugging
- Faster testing
- No compilation required

---

## Dynamically Typed

You do not need to define variable types manually.

Example:

```python
name = "John"
age = 25
```

Python automatically detects the data type.

---

## Object-Oriented

Python supports Object-Oriented Programming (OOP).

Concepts include:
- Classes
- Objects
- Inheritance
- Polymorphism

---

## Open Source

Python is completely free to use and distribute.

Official website:

# Python Syntax Rules

## Case Sensitive

Python is case-sensitive.

Example:

```python
name = "Python"
Name = "Programming"
```

Both variables are different.

---

## Indentation Matters

Python uses indentation instead of curly braces.

Correct example:

```python
if True:
    print("Hello")
```

Incorrect example:

```python
if True:
print("Hello")
```
