# Python vs C

## Overview

C is one of the oldest and fastest programming languages.

Python is more modern and easier to use.

---

# Syntax Comparison

## Python

```python
print("Hello")
```

## C

```c
#include <stdio.h>

int main() {
    printf("Hello");
    return 0;
}
```

Python requires much less code.

---

|---|---|---|

# Python vs Java

## Overview

Java is widely used in enterprise applications.

Python focuses more on simplicity and rapid development.

---

# Syntax Comparison

## Python

```python
print("Hello")
```

## Java

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```

Python code is shorter and more readable.

---

| Typing | Dynamic | Static |

| Use Cases | AI, Scripting | Enterprise Applications |
