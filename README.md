## Python Data Types
<img width="888" height="412" alt="image" src="https://github.com/user-attachments/assets/332273e8-f504-4293-ba5b-52ac008b8e57" />

### [Strings](https://www.geeksforgeeks.org/python-string/)
Strings in Python are sequences of characters enclosed within single or double quotes. They are used to represent text and can be manipulated with various string methods, such as concatenation, slicing, and formatting.

### [Numbers](https://www.geeksforgeeks.org/python-numbers/)
Python supports various types of numbers, including:
- **Integers (`int`)** – numbers without decimal points  
- **Floating-point numbers (`float`)** – numbers with decimal points  
- **Complex numbers (`complex`)** – example: `2 - 3i`  

These numeric types allow for a wide range of mathematical operations, such as addition, subtraction, multiplication, and division.

### [Booleans](https://www.geeksforgeeks.org/boolean-data-type-in-python/)
Booleans in Python represent truth values: `True` and `False`. They are often used in conditional statements to control the flow of a program based on logical conditions.

### [Python List](https://www.geeksforgeeks.org/python-list/)
A Python list is an ordered collection of elements, which can be of different data types. Lists are mutable, meaning elements can be added, removed, or modified. They are created using square brackets, e.g., `[1, 2, 3]`.

### [Python Tuples](https://www.geeksforgeeks.org/python-tuples/)
Tuples are similar to lists but are immutable, meaning their elements cannot be changed after creation. Tuples are defined using parentheses, e.g., `(1, 2, 3)`, and are often used to store related data that should not be altered.

### [Python Sets](https://www.geeksforgeeks.org/python-sets/)
A Python set is an unordered collection of unique elements. Sets are mutable, allowing elements to be added or removed, but they do not allow duplicate values. Sets are created using curly braces, e.g., `{1, 2, 3}`.

### [Python Dictionary](https://www.geeksforgeeks.org/python-dictionary/)
A Python dictionary is a collection of key-value pairs, where each key is unique and is used to retrieve its corresponding value. Dictionaries are mutable and are defined using curly braces with key-value pairs separated by colons, e.g.:
```python
{'name': 'Alice', 'age': 30}
```
Here, `name` and `age` are keys, while `Alice` and `30` are values.

### [Type Casting](https://www.geeksforgeeks.org/type-casting-in-python/)
Type casting in Python is the process of converting a variable from one data type to another. For example:
- Convert an integer to a string using `str()`
- Convert a string to a float using `float()`  

This is useful when working with different data types in a program.
